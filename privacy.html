MacShorts 개인정보처리방침

시행일: 2026-10-10

1. 이 앱이 쓰는 권한

MacShorts는 Google 계정의 YouTube 동영상 업로드 권한(https://www.googleapis.com/auth/youtube.upload) 하나만 요청합니다. 이 권한은 운영자가 승인한 영상을 운영자 본인의 채널에 올리는 데만 씁니다.

2. 처리하는 정보

Google 로그인으로 받은 인증 토큰만 다룹니다. 토큰은 운영자의 Mac 안에, 운영자만 읽을 수 있는 파일로 저장합니다. 채널의 다른 영상, 구독자, 시청 기록 같은 정보는 읽지 않습니다.

3. 제공과 공유

받은 정보를 누구에게도 판매, 제공, 공유하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

4. 보관과 삭제

토큰은 앱을 쓰는 동안만 보관합니다. Google 계정의 서드파티 액세스 화면에서 언제든 접근 권한을 해제할 수 있고, 해제하면 토큰은 더 이상 쓸 수 없습니다.

5. Google API 서비스 사용자 데이터 정책

MacShorts는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

Summary in English

MacShorts requests only the YouTube upload scope, uses it solely to upload the owner's approved videos to the owner's own channel, stores the OAuth token only on the owner's Mac, and never sells or shares any data. Access can be revoked at any time from the Google Account permissions page.
